# О игре «Ружун»

**Ружун** — браузерная 3D-игра (three.js + Vite, от третьего лица). Ты — одно из
существ на **небесных островах**, заросших джунглями. Мир бесконечный, делится
на чанки и строится целиком через seed: острова, леса, животные, поселения, NPC,
артефакты.

## Главная идея

Ты живёшь среди **небесных островов**, парящих в небе и связанных джунглями.
Некоторые острова — древние руины зданий (до 5+ этажей). Цель игры — выживать:
добывать артефакты, снадобья и побеждать опасных зверей.

## Как начать

- Вводи **seed мира** в стартовом меню или оставляй пустым для случайного мира.
- Один и тот же seed → один и тот же мир (острова, растения, животные, поселения).
- Движение: `W A S D`, взгляд мышью (pointer-lock), взаимодействие `E`, огонь `ЛКМ`.

## Что есть в мире

- **Небесные острова** — парящие платформы с джунглями и руинами зданий.
- **Фрукты** — повышают прыгучесть; съев их, можно перепрыгнуть между не самыми
  дальними островами силой ног. Из них варят прыгающий эликсир (ещё эффективнее).
- **Торговцы на дирижаблях** — редкие путешественники с товарами (обмен за вещи/кристаллы).
- **Кристаллы** — разных размеров, названий и ценности: добываются в пещерах на
  островах и выпадают из глаз животных (глаза сделаны из тех же кристаллов).
- **Призывание внимания** — покричать и помахать рукой можно привлечь животных,
  людей и торговцев даже на далёких островах.

## Системы игры

1. NPC-персонажи — игрок один из них (единое тело/анимации/физика).
2. Система растений (плоды, семена, деревья).
3. Строительство зданий.
4. Социальные отношения: семьи, дружба, вражда, плен.
5. Плюшевые животные (мишки, волки, зайцы, лисы и др.).
6. Медикаменты и снадобья.
7. Траверс — путешествия между островами.
8. Острова (небесные платформы, чанки).
9. Пещеры.
10. Торговля / обмен / подарки.
11. Крафт: одежда, оружие, лекарства.
12. Одежда на NPC/игроке.
13. Групповое взаимодействие (плюшевые волки в набеге против деревни).
14. Поселения и караванные пути.
15. Кочующие торговцы на дирижаблях.
16. Сложные анимации, включая согласованные парные движения в бою.
17. Облака (генерация через seed).
18. Смена дня и ночи (рассветы, закаты).
19. Смена погоды (дождь, туман, роса, солнечно, облачно).
20. Бабочки.
21. Ожерелья из трофейных зубов/членов/бусин/драгоценных камней.
22. Загар: солнечная погода оставляет следы от одежды на теле (для светлой/средней/тёмной кожи), плавное стирание со временем.
23. Тело-артефакты из предков (заячьи ушки, рога и т.д.), суммирование артефактов тела.

## Технологии

- **three.js** — 3D-графика.
- **Vite** — сборка и dev-сервер (порт 7001).
- Чистый JS без фреймворков, модули ES (`import`/`export`).
- Детерминированный RNG (`mulberry32`, хэши координат) в `src/core/rng.js` — основа генерации мира.

## Команды

```bash
npm run dev      # dev-сервер, http://localhost:7001/
npm run build    # продакшн-сборка в dist/
npm run preview  # просмотр сборки локально
```
