# AGENTS.md — Ружун

Памятка для ИИ-ассистента при работе над этим проектом. Читается при каждой сессии.

## Что это за проект

Браузерная игра «Ружун» (three.js + Vite, чистый JS без фреймворков).
**Небесные острова**, заросшие джунглями: растения, животные, поселения, NPC,
артефакты, крафт, строительство. Мир бесконечный, делится на чанки, строится
через seed.

- Язык интерфейша и комментариев: **русский**.
- UI-текст и подсказки — тоже русский.
- Одинокий `index.html`, код в `src/`, сборка Vite.

### Ключевая концепция (НЕ ЛОМАТЬ)

**Игрок — один из NPC по всем параметрам, анимациям и остальному.** Это не две
отдельные ипостаси. Если какая-то анимация/логика не работает для игрока — значит
она так же не работает для NPC. Не заводить «игрок = особый случай» без крайней
необходимости: NPC-тело, NPC-анимации, NPC-физика должны покрывать и игрока.

## Команды

- Dev-сервер: `npm run dev` (порт 7001, `--host`). Игра: http://localhost:7001/
- Сборка: `npm run build` (важно проверять после изменений).
- Проверка синтаксиса конкретного файла: `node --check src/...`.

### Как запустить игру (ВАЖНО)

Dev-сервер — долгоживущий процесс: прямое выполнение `npm run dev` в оболочке
умирает по таймауту терминала (запуск обрывается, игра «не запускается»).
Запускать ТОЛЬКО в фоне через `Start-Process` и проверять готовность по порту:

```powershell
$out = Join-Path $env:TEMP "rujun-dev.out.log"
$err = Join-Path $env:TEMP "rujun-dev.err.log"
$p = Start-Process -FilePath "npm.cmd" -ArgumentList "run","dev" `
  -WorkingDirectory "D:\nf-games\rujun" `
  -RedirectStandardOutput $out -RedirectStandardError $err `
  -PassThru -WindowStyle Hidden
Start-Sleep -Seconds 6
if ($p.HasExited) { "ПРОЦЕСС УПАЛ, код=$($p.ExitCode)"; Get-Content $out,$err }
```

- `npm` — это `npm.cmd` (иначе `Start-Process` не найдёт исполняемый файл).
- stdout/err — РАЗНЫЕ файлы (`Start-Process` не даёт один на оба потока).
- Готовность: `Get-NetTCPConnection -LocalPort 7001 -State Listen` либо
  `Invoke-WebRequest http://localhost:7001/` → HTTP 200.
- Остановить: `Stop-Process -Id <PID>` (PID из OwningProcess на порту 7001).

## Структура src/

- `main.js` — точка входа: сцена/рендер/камера, игровой цикл `frame()`,
  обработка ввода, старт игры. Время в цикле считается через `performance.now()`
  (`perfDt`) — НЕ через `THREE.Clock` (он был убран).
- `core/rng.js` — детерминированный RNG: `mulberry32`, хэши координат/строк,
  value-noise/fbm. Основа всей генерации мира от seed.
- Дальнейшие модули появятся по мере реализации систем (см. GOALS.md):
  `world/` (чанки, острова, поселения), `player/`, `items/`, `ui/`, `audio/`.

## Ключевые концепции и правила (НЕ ЛОМАТЬ)

### ⚠️ ЗОЛОТЫЕ ПРАВИЛА (нарушение = сломанный проект)

1. **Игрок = NPC.** Единый персонаж: тело, анимации, физика, лут-подбор — всё
   общее. Никаких «особых путей» для игрока там, где это можно выразить через
   общий код NPC.
2. **Мир детерминирован от seed.** Один и тот же seed → один и тот же мир
   (острова, растения, животные, поселения, NPC). Повторный заход с тем же seed —
   та же локация. Генерация через `hashStr`/`mulberry32`, поток rng строго
   сохраняется при разбивке на подшаги.
3. **Игрок появляется в случайном месте мира.** Случайные координаты задают, в
   каком чанке окажемся; seed вводится в начале игры или остаётся пустым для
   случайности.
4. **Подбор лута — ТОЛЬКО по перекрестию.** Никогда не использовать «ближайший
   предмет» — только `aimInteractive()` / перпендикуляр к лучу взгляда.
5. **РОВНО ОДНА подсказка на объект.** Не может быть двух подсказок у одного
   объекта/предмета/NPC одновременно.
6. **Не добавляй функции/UI/тексты, которые не запрошены.** Если кажется, что
   стоит добавить — спросить пользователя, не делать самому.
7. **Перед коммитом: прогнать ВСЕ смоуки** + `_regression.mjs`. Если хоть один
   упал — НЕ КОММИТИТЬ.
8. **Не менять работающие формулы без явного запроса.** При правке системы A
   убедиться, что зависящие от неё B/C/D не сломались — запустить смоуки.
9. **При рефакторинге — сначала зафиксируй ТЕКУЩЕЕ поведение смоуком, потом меняй.**
   Не «улучшай» то, что работает, без запроса.

## Мир и механика (из описания игры)

- **Небесные острова** в джунглях; руины древних зданий до 5+ этажей.
- Фрукты повышают прыгучесть — можно перепрыгивать между не самыми дальними
  островами силой ног. Из них — прыгающий эликсир (ещё эффективнее).
- Редкие **торговцы на дирижаблях** с товарами (обмен за вещи/кристаллы).
- **Кристаллы** разных размеров/названий/ценности: в пещерах на островах и из
  глаз животных (глаза сделаны из тех же кристаллов).
- **Привлечь внимание** животных/людей/торговцев (в т.ч. на далёких островах) —
  покричать и помахать рукой.
- Цель: выживать, не попадаться опасным зверям или побеждать их; нужны артефакты
  и снадобья.

1–23 системы из описания: NPC/игрок как единое существо, растения, строительство,
социальные отношения (семьи/дружба/вражда/плен), плюшевые животные, медикаменты,
траверс между островами, острова, пещеры, торговля/обмен/подарки, крафт, одежда,

кочующие торговцы, сложные анимации (в т.ч. парные), облака, день/ночь, погода,
бабочки, ожерелья из трофейных зубов/членов/бусин/камней, загар по погоде с
плавным стиранием следов от одежды, тело-артефакты (заячьи ушки, рога и т.д.).
